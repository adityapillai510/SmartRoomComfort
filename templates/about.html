ABOUT THE PROJECT

Smart Room Comfort Level

A web-based system that uses fuzzy logic to analyse room conditions.

🎯 Project Objective

The objective of this project is to develop an intelligent room comfort assessment system using fuzzy logic.

🌡️ Analyse temperature
💧 Analyse humidity
🧠 Apply fuzzy logic
📊 Calculate comfort score
🌀 Recommend fan speed

🧠 What is Fuzzy Logic?

Fuzzy logic allows values to have different degrees of membership instead of only being completely true or false.

Temperature

Low / Moderate / High

Humidity

Low / Moderate / High

Comfort

Low / Medium / High

⚙️ Methodology

1

Fuzzification

Converts input values into fuzzy membership values.

2

Fuzzy Rules

Applies predefined IF-THEN fuzzy rules.

3

Inference

Combines the activated fuzzy rules.

4

Defuzzification

Converts the fuzzy output into a numerical score.
